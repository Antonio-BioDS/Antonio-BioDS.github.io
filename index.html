Featured Projects

Selected technical projects in AI and Data Science

Predictive Customer Churn Model | TripleTen

Developed a supervised Machine Learning system to predict customer attrition in the telecommunications industry. Implemented model interpretability techniques using SHAP to identify key loss drivers, achieving a ROC-AUC score of 0.91.

Results: Final Gradient Boosting model achieved AUC-ROC 0.91 and Recall 0.74 for churners. This represents a reliable predictive model for issuing alerts and implementing actions to address churn. Furthermore, conditions linked to churn were identified, which would allow for both the improvement and proper monitoring of these conditions to enhance user retention.
Python Scikit-Learn LightGBM SHAP

Data Extraction & Transportation Usage Patterns | TripleTen

Performed automated data extraction, cleaning, and mining on multi-source transportation datasets using SQL and Python. Discovered key usage patterns and high-demand routes to support revenue optimization strategies.

Results: The Pareto principle was observed in action, identifying the 20% of routes that generated 80% of the revenue —a key insight for increasing availability on those routes and optimizing profits..
